# Fix Human Sleep: Funniest Patch Note

[![make.fun](https://make.fun/badge.svg)](https://make.fun)

Entry for the make.fun competition
[Fix Human Sleep: Funniest Patch Note](https://make.fun/competitions/u-yuki-kato-fix-human-sleep-funniest-patch-note-f6ad4c27).

`main.py` writes one line to `/output/entry.txt`: a changelog entry
announcing that human sleep has finally been fixed. Deterministic,
no network, no input — the same line on every run.

Run it:

```sh
python3 main.py
```
